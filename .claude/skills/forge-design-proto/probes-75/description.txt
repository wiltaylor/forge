Forge design system — build dense, dark-default technical UIs (dashboards, consoles, observability panels, admin screens) on three platforms: SolidJS on the web, ratatui for TUIs, and egui for native desktop apps. Beyond the usual primitives, shell, forms, overlays, feedback and tables, it covers a chat kit (transcripts, tool-call boxes, interactive prompts), pie/line/bar/gantt charts and sparklines, a code and diff editor, node graphs and flowcharts, a command palette, and a Markdown renderer. Also covers the Forge backend contract — doc store, actions, events, SSE — in axum and FastAPI, and Tauri v2 IPC transport and desktop packaging. Use when building or styling a Forge UI, choosing colours or tokens, adding a control, or wiring a Forge backend; or when the user says "use the design system", "Forge style", "match the console look".
